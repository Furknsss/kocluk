# kocluk

## Uygulamayı telefona veya tablete yükleme

Site bir Progressive Web App (PWA) olarak çalışır. Güncel dosyaları HTTPS üzerinden yayınlayın; servis çalışanı HTTPS veya `localhost` gerektirir.

- Android/Chrome: Siteyi açın ve **Uygulamayı yükle** düğmesine dokunun. Tarayıcı kurulum penceresini gösterir.
- iPhone/iPad: Siteyi Safari’de açın, paylaş menüsünden **Ana Ekrana Ekle** seçeneğini kullanın.

Uygulama ana ekrandan bağımsız pencere olarak açılır ve daha önce yüklenmiş sayfa ile arayüz kaynakları çevrimdışıyken önbellekten sunulur. Google Sheets eşitlemesi için internet bağlantısı gerekir.
